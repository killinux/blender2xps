安装与启用

仓库结构：

blender2xps/            插件本体（一个 Python 包）
tools/                  命令行工具：xpsdump / batch_export_blends / write_export_index / blender_mcp
tests/                  端到端测试
docs/使用指南.md        本文的 Markdown 版本
install.ps1             安装脚本

方式 A：联接安装（推荐，改代码即生效）

cd E:\code\othercode\blender2xps
.\install.ps1              # Blender 3.6
.\install.ps1 3.6,4.2      # 同时装到多个版本

脚本在 %APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\blender2xps 建一个指向仓库的目录联接。加 -Copy 则改为复制一份。

方式 B：手动

把 blender2xps 文件夹整个复制到上面的 addons 目录；或者打成 zip，在 Edit > Preferences > Add-ons > Install... 里选 zip（4.2+ 用右上角下拉菜单的 Install from Disk）。

启用

Edit > Preferences > Add-ons，搜索 Blender2XPS，勾选，点左下角 Save Preferences。启用后：

  • 3D 视口侧边栏（按 N）多出 XPS 页签；
  • File > Export 菜单多出 XPS / XNALara (.xps/.mesh/.ascii) [Blender2XPS]。

Blender 正在运行且装了 blender-mcp 插件时，可以不点鼠标直接启用或热重载：

python tools\blender_mcp.py enable     # 启用并保存偏好
python tools\blender_mcp.py reload     # 改完代码后重载

三步导出

选骨架点一下骨架（或它绑定的任意网格），面板“目标骨架”会显示自动识别的结果；多副骨架的场景可在“骨架”框里指定。
检查模型点 检查模型。弹窗列出骨架统计、每个网格的权重情况、每个材质会用的渲染组和贴图、会被跳过的物体。完整内容在文本编辑器的 blender2xps_report 文本块和系统控制台里。这一步不写任何文件。
导出设置“输出文件”，点 导出...，在文件浏览器里确认路径和选项。状态栏显示 已导出 xxx.xps | 骨骼 n | 网格 n | 顶点 n | 三角面 n | 警告 n；同目录有贴图和 xxx.xps.report.txt。点 打开输出目录 直接打开文件夹。

也可以走 File > Export 菜单：选项在文件浏览器右侧，和面板一样；菜单会记住上次的设置，面板的“导出...”按钮则使用面板里的设置。

导出不会改动场景。修改器开关、材质、选择状态在导出结束后全部恢复；烘焙用的是材质副本。

面板选项逐项说明

范围与几何
选项默认说明
导出范围骨架绑定的全部网格骨架绑定的全部网格：绑定到目标骨架的所有网格。仅选中的物体：只导选中的网格（只选了骨架时导出绑定到它的全部网格）。全部可见网格：视图层里所有可见网格，多副骨架时用这个。
跳过隐藏物体开隐藏的网格不导出。mmd_tools 的刚体、关节物体无论如何都不导出。
应用修改器开导出计算后的网格：镜像、细分、形态键当前混合结果等。骨架修改器始终按静止姿态处理，不会被烘进网格。
把当前姿态烘焙为绑定姿态关用当前姿态下的网格和骨骼位置作为 XPS 的默认姿态。比如把 A-pose 摆成 T-pose 后导出。
缩放1.0整体乘以的比例。XPS 角色通常 1.5～1.9 单位高；厘米单位的模型（UE 导出）填 0.01。
导出顶点色开写入活动颜色属性；没有就写白色。
导出全部 UV 层关默认只写第一层 UV（XPS 只用第一层，光照贴图用第二层）。
自动转正朝向开按眼球（其次脚踝→脚趾）方向判断角色朝向，整体绕 Z 轴旋转让角色面向 XPS 观众（Blender 的 -Y）。没识别到眼睛或腿骨就不处理。
骨骼与权重
选项默认说明
每顶点最多权重数4超过的按权重大小截断，然后重新归一化到和为 1。0 = 不限制（只对 v3 / ASCII 格式有效；v2 和经典 .mesh 固定 4 个）。
无权重顶点绑定到根骨没有任何骨骼权重的顶点怎么办：绑定到根骨 / 绑定到最近的骨骼 / 保持 0 权重（XPS 里会塌到原点，不推荐）。用骨骼父级方式挂接的网格会绑到那根父骨。
骨骼命名映射为 XPS 标准骨名识别 MMD（日文、.L/.R、mmd_tools 英文）、3ds Max Biped / Bip001、Mixamo、VRoid、VRM、Rigify、UE4/UE5 mannequin、MetaHuman 的骨名，改成 XPS 标准名：root ground、root hips、spine lower/middle/upper、head neck lower/upper、arm left shoulder 1/2、arm left elbow/wrist、arm left finger 1a…5c、leg left thigh/knee/ankle/toes、head eyeball left/right、head jaw。其余保持原名。改成标准名后社区的 .pose 文件可以直接用。
其余骨名转成 ASCII关未映射的日文骨名按 mmd_tools 词典翻译成英文（腰キャンセル.L → WaistCancel.L）。XPS 本身读 UTF-8 没问题；只在要用 XNALaraMesh 导回 Blender、或其他只认 ASCII 的工具时勾选。
合并 MMD 辅助骨开足D/ひざD/足首D 并入 足/ひざ/足首，腕捩/手捩(1-3) 并入 腕/ひじ，肩C/肩P 并入 肩，腰キャンセル 去掉；权重和子骨一起转移。不合并的话 XPS 里转动主骨骼网格不会动（权重都在 D 骨上）。
去掉 mmd_tools 内部骨开去掉 _dummy_ / _shadow_ 开头且没有权重的约束辅助骨。
父骨排在子骨前面开骨骼列表按层级重排，保证父骨索引小于子骨。
隐藏辅助骨 (unused 前缀)开扭转骨、肌肉修正骨、IK / 附件骨等加 unused_ 前缀：XPS 骨骼列表里不显示，但仍参与蒙皮（XNALara 约定）。识别出的 XPS 标准骨永远不会被隐藏。
隐藏面部骨关MetaHuman 风格的 FACIAL_* 骨（600 多根）加 unused_ 前缀；下颌、眼球、舌头保留可见。
材质与文件
选项默认说明
文件格式自动自动：路径以 .ascii 结尾写文本格式，否则写 XPS 二进制（权重上限 ≤4 用 v2.15，否则 v3.15）。其余见格式速查。扩展名会按格式自动改正。
透明材质自动检测自动：材质混合模式不是 Opaque、且漫反射贴图在这个部件自己的 UV 上采样有 ≥8% 的透明像素，才用带 alpha 的渲染组；mmd 材质 alpha < 1 直接算透明。全部不透明 / 全部透明 强制。
材质烘焙自动自动：颜色或透明由节点算出来的材质（颜色渐变驱动的头发、拆通道当 alpha 的睫毛、程序化虹膜、带明显色调的皮肤等）用 Cycles 发光烘焙成一张 RGBA PNG；贴图直连 Base Color 的材质不烘，保留原分辨率。全部烘焙 / 不烘焙。
烘焙尺寸00 = 取材质里贴图的尺寸，最小 512、最大 2048；也可以填 1024 / 4096。
跳过半透明辅助壳开固定 alpha < 0.5 的材质（眼部遮蔽壳、泪线、假反射片）不导出。完全透明（alpha = 0）的材质无论如何都跳过。
无光照渲染组 (卡通)关用渲染组 10/21（不受光照），适合 MMD 卡通贴图。
高光值0.1写进部件名的高光强度，XPS 里可再调。
复制贴图到输出目录开用到的贴图复制到模型旁边；打包图、.hdr/.exr/.tif/.psd 等 XPS 不认的格式自动转成 PNG；没有漫反射贴图的材质生成一张 4×4 纯色 PNG。
网格名转成 ASCII开部件名里的非 ASCII 字符按词典翻译或去掉。
去掉部件名的公共前缀开Fiona_Face / Fiona_Hair → Face / Hair。
写导出报告 (.report.txt)开见第 6 节。

按模型来源的推荐设置

mmd_tools · PMX

MMD 模型

  • 默认设置就是为它准备的：合并 MMD 辅助骨、映射 XPS 骨名、4 权重、自动透明检测。
  • 点击骨架或身体网格再导出；刚体、关节物体自动跳过。
  • 身体贴图的 alpha 通道常塞了别的数据（*_rgbx_*），按部件 UV 采样不会把身体误判成透明。
  • 带 VMD 姿态时导出的是静止姿态；想导出当前姿态勾“把当前姿态烘焙为绑定姿态”。
UE Viewer / FModel · UE4 / UE5

游戏提取的 UE 模型（Vindictus、FF7 等）

  • 缩放填 0.01（厘米 → XPS 单位）。报告里“模型高度 184 单位”的警告就是提醒这个。
  • 范围用“全部可见网格”（一副合并骨架 + 多个部件）。
  • 材质烘焙保持“自动”：头发、眼球、睫毛一定要烘焙，否则 XPS 里是白眼球、乱色头发。
  • 隐藏辅助骨保持开；MetaHuman 面部骨太多时勾“隐藏面部骨”。
  • 每个模型 1～5 分钟，主要花在 2048 烘焙上；赶时间把烘焙尺寸设 1024。
FBX · Rigify · Mixamo · VRoid

一般绑定角色

  • 常见骨名都会映射；Rigify 请导出生成的 DEF 骨架而不是控制骨架（控制骨没有权重）。
  • 有镜像、细分修改器时保持“应用修改器”开。
  • 缩放看报告里的高度：Blender 里 1.7 m 高就填 1。
无骨架

静态物体（道具、场景）

  • 没有骨架也能导：自动加一根 root ground 骨，所有顶点权重 1 绑到它。

用名字和属性控制单个部件

写在哪里效果
材质自定义属性 xps_render_group（整数 1～43）强制该材质的渲染组，贴图槽按该组要求填充
材质自定义属性 xps_alpha（0 / 1）强制不透明 / 透明
材质自定义属性 xps_specular（小数）该部件的高光值
物体名以 数字_ 开头（如 7_hair，XNALaraMesh 的命名习惯）当作渲染组覆盖，前缀不会出现在部件名里
物体名以 + / - 开头XPS 可选部件（默认显示 / 默认隐藏）

自定义属性在 Properties > Material > Custom Properties 里添加。

部件名生成规则：<渲染组>_<名字>_<高光>_0_0。名字来自物体名（多材质时加材质名；只有一个物体时只用材质名），Blender 的 .001 后缀和下划线（XPS 的分隔符）会被清理，重名自动加序号。

渲染组自动选择：只有漫反射 → 5/7，加法线 → 4/6，加高光 → 40/41，加自发光 → 36/37，加光照贴图 → 3/9 或 2/8；偶数不透明、奇数透明；卡通 → 10/21。

导出报告怎么读

<文件>.report.txt 分两段。头部：

文件 / 格式 / 耗时
骨骼 260  网格部件 11  顶点 50301  三角面 73813  每顶点最多权重 4
包围盒 (XPS 坐标): ... -> 高度 1.783          # 高度不在 1.5~2 附近要看缩放
改名的骨骼 (55): 全ての親->root ground, ...     # 骨名映射结果
合并的骨骼 (28): 足D.L->足.L, ...              # 权重去了哪根骨
去除的骨骼 (62): _dummy_...                    # 没有权重的内部骨
XPS 列表中隐藏的辅助骨 (260, 前缀 unused_): ...
跳过的物体 (100): xxx(mmd_tools 刚体/关节); yyy(隐藏); zzz(未绑定到骨架 ...)
写出贴图 7 个

正文按网格列出：每个部件一行（部件名、顶点、三角面、渲染组、贴图文件），以及：

  • 警告: ... N 个顶点没有骨骼权重，已绑定到根骨：检查这些顶点是否本该有权重。
  • N 个顶点超过 4 个权重，已按权重大小截断并重新归一化：正常；v3 格式可不截断。
  • 忽略非骨骼顶点组: mmd_edge_scale, ...：名字不是骨骼的顶点组，正常。
  • 烘焙材质 xxx -> 2048x2048 / 跳过材质 xxx: 完全透明 | 半透明辅助壳。
  • 没有漫反射贴图，已生成纯色贴图：材质里找不到图片，XPS 里会是纯色。
  • 渲染组 N 需要 bump 贴图但材质里没有：手动指定的渲染组缺贴图，写成 missing.png。
  • 文件校验: ...：写完回读文件发现的问题（索引越界、权重和不为 1 等），出现即为错误。
错误: 开头的条目说明文件有问题，不要拿去用。

在 XPS 里加载和检查

  1. 打开 XNALara XPS（11.8 及以上都能读默认的 v2.15 格式）。
  2. Modify > Load Generic_Item...，选导出的 .xps；贴图在同目录会自动找到。
  3. 检查项：模型面向你、脚在地面附近、高度和其他 XPS 模型接近；打开 Bones 面板，root hips / arm left elbow / leg left knee 等能找到，转动一根主骨对应部位跟着动；头发、睫毛边缘透明正确；身体没有闪烁（闪烁说明被判成透明，见排错）；unused_ 开头的骨不出现在列表里。
  4. 想保存成 XPS 自己的格式：File > Save Generic_Item。

批量导出（无头模式）

& "D:\Program Files\blender-3.6.15-windows-x64\blender.exe" -b --python tools\batch_export_blends.py -- `
    --out D:\out --scale 0.01 --bake AUTO a.blend b.blend c.blend
参数说明
--out <目录>每个 .blend 输出到 <目录>\<名字>\<名字>.xps
--scale 0.01缩放
--scope VISIBLE|ARMATURE|SELECTED导出范围，默认 VISIBLE
--bake AUTO|ALL|OFF材质烘焙，默认 AUTO
--bake-size 1024烘焙尺寸，默认按贴图尺寸
--fmt AUTO|XPS2|XPS3|MESH|ASCII文件格式
--bone-naming XPS|KEEP骨骼命名
--max-weights 4每顶点权重上限
--hide-facial隐藏面部骨
--no-facing关闭自动转正朝向

每个文件打印一行 BLENDER2XPS_BATCH={...json...}，含 ok / bones / meshes / stats / warnings / errors，方便脚本收集。多开几个 Blender 进程并行即可（每个进程峰值内存约 2.5 GB）。导完后生成索引页：

python tools\write_export_index.py D:\out [manifest.json]

会在 D:\out\README.md 写一张表：每个模型的骨骼数、标准骨数、隐藏骨数、部件、顶点、三角面、烘焙 / 跳过材质数、警告数、校验结果、大小。

脚本调用

import bpy
from blender2xps import export_xps

settings = export_xps.Settings(
    filepath=r'D:\out\model.xps',   # 扩展名会按格式改正
    fmt='AUTO', scope='ARMATURE', scale=1.0,
    bone_naming='XPS', mmd_merge_helpers=True,
    bake_mode='AUTO', alpha_mode='AUTO')
result = export_xps.export_model(bpy.context, settings)
print(result.summary())      # 一行汇总
print(result.warnings)       # 警告列表
print(result.report_text)    # 完整报告

Settings 的字段名和面板选项一一对应：scope、visible_only、apply_modifiers、bake_pose、scale、max_weights、unweighted、bone_naming、ascii_bone_names、mmd_merge_helpers、drop_internal_bones、sort_bones、hide_helper_bones、hide_facial_bones、ascii_mesh_names、copy_textures、alpha_mode、bake_mode、bake_size、skip_translucent、unlit、specular、vertex_colors、all_uv_layers、strip_common_prefix、auto_facing、write_report、armature_name。传错名字会立刻抛 TypeError。

只检查不导出：export_xps.analyze(bpy.context, settings) 返回文本行列表。操作符：bpy.ops.blender2xps.export(filepath=..., fmt='ASCII', scope='ARMATURE')。

常见问题排查

现象原因解法
XPS 里模型碎成一团或缩向原点顶点没有权重 / 权重和不为 1（老插件的典型问题）本插件默认归一化并把无权重顶点绑到根骨；看报告“没有骨骼权重”的数量，确认这些顶点在 Blender 里是否本该有权重
转动主骨骼，网格不动（MMD）权重在 足D、腕捩 等辅助骨上开“合并 MMD 辅助骨”（默认开）
模型只有几厘米高，或大得看不见单位不对（UE 模型是厘米）缩放 0.01 / 100；报告和“检查模型”都会提示高度
模型背对或侧对观众源文件朝向不是 -Y“自动转正朝向”默认开；仍不对就在 Blender 里旋转骨架物体（连同网格）后导出
身体闪烁、半透明被判成透明渲染组材质加 xps_alpha = 0，或“透明材质 = 全部不透明”；检查贴图 alpha 通道是否真的是透明信息
头发、睫毛边缘是黑块贴图没有 alpha，或颜色 / 透明由节点计算材质烘焙“自动”会处理；仍不行就“全部烘焙”
眼球是白的 / 头发颜色像遮罩图程序化材质没烘焙材质烘焙设为“自动”或“全部烘焙”
贴图是纯色或 missing.png材质节点里找不到图片看“检查模型”里该材质的“贴图”列；贴图要接到 Principled 的 Base Color / Normal，或用烘焙
